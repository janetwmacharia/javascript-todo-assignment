# JavaScript To-Do List Application

## Project Description
A simple interactive To-Do List application built using HTML, CSS and JavaScript.

The application allows users to manage their daily tasks.

## Features
- Add new tasks
- Display tasks
- Mark tasks as completed
- Delete individual tasks
- Prevent empty task entries
- Task counter
- Clear all tasks
- Save tasks using localStorage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
